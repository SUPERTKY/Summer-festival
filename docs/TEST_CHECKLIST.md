# 動作確認チェックリスト

Studio の **Test → Start** でサーバー1台・プレイヤー2〜3人を起動します。

## スタッフ

- [ ] 募集ブロックへ触れると確認画面が出る
- [ ] 「やめておく」でスタッフにならない
- [ ] 「スタッフになる」で `WorkAnchor` へ移動する
- [ ] 歩行とジャンプはできず、左右回転だけできる
- [ ] カメラが一人称になり、常にキャラクターの正面を向く
- [ ] マウス移動では視点が変わらず、PCではA/Dだけで回転する
- [ ] 同じ屋台で2人目のスタッフを登録できない
- [ ] 辞任すると移動・ジャンプが元に戻る
- [ ] 辞任すると以前のカメラ設定へ戻る
- [ ] 退室またはリスポーン後にスタッフ枠が解放される

## 展示板とメッシュ

- [ ] 屋台上の板の左側に現在の工程のバナナが1つ表示される
- [ ] 工程が進むたびに `Banana → PeeledBanana → SkeweredBanana → DippedBanana → FinishedBanana` へ置き換わる
- [ ] 登録した別メッシュの `SkeweredBanana` が串刺し工程後の手持ちへ使われる
- [ ] 完成品が板上の `DisplayPoint` に置かれる
- [ ] コマンドバーコードを再実行しても板・工程位置・販売位置が重複しない

## 作成工程

- [ ] バナナを取ると皮なしの `PeeledBanana` が左手に表示される
- [ ] 用意した皮付きバナナ・皮なしバナナ・棒のメッシュが表示される
- [ ] バナナより先に棒を取れない
- [ ] 棒を取ると右手に表示される
- [ ] 「バナナを刺す」で登録した `SkeweredBanana` へ変わる
- [ ] チョコ筒を選ぶと筒の方向へ固定される
- [ ] 漬け終わると回転できるようになる
- [ ] トッピング開始1秒後から粒が下向きに3秒流れる
- [ ] チョコ後と完成品に用意したメッシュが使われる
- [ ] 販売ブロックで `DisplayPoint` の位置・回転に商品が置かれる
- [ ] 販売中の商品が残っている間は次の商品を置けない

## 購入と所持金

- [ ] 初回所持金が100円で表示される
- [ ] スタッフは商品を購入できない
- [ ] 一般客が購入すると50円になり、`FinishedBanana` メッシュのToolを受け取る
- [ ] 残高不足では購入できず、商品も残る
- [ ] 同じ商品を2人が同時購入しても1回分だけ処理される

## セキュリティ確認

- [ ] 工程を飛ばして設備を選んでも進まない
- [ ] 別の屋台の設備で工程を進められない
- [ ] RemoteEventへ不正な文字列を送っても状態が変わらない
