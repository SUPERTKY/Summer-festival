# 動作確認チェックリスト

Studio の **Test → Start** でサーバー1台・プレイヤー2〜3人を起動します。

## スタッフ

- [ ] 募集ブロックへ触れると確認画面が出る
- [ ] 「やめておく」でスタッフにならない
- [ ] 「スタッフになる」で `WorkAnchor` へ移動する
- [ ] 歩行とジャンプはできず、左右回転だけできる
- [ ] カメラが一人称になり、常にキャラクターの正面を向く
- [ ] マウス移動では視点が変わらず、PCではA/Dだけで回転する
- [ ] 同じ屋台で2人目のスタッフを登録できない
- [ ] 辞任すると移動・ジャンプが元に戻る
- [ ] 辞任すると以前のカメラ設定へ戻る
- [ ] 退室またはリスポーン後にスタッフ枠が解放される

## 展示板とメッシュ

- [ ] 屋台上の板の左側に現在の工程のバナナが1つ表示される
- [ ] 工程が進むたびに `Banana → PeeledBanana → SkeweredBanana → DippedBanana → FinishedBanana` へ置き換わる
- [ ] 登録した別メッシュの `SkeweredBanana` が串刺し工程後の工程展示へ使われる
- [ ] 完成品が板上の `DisplayPoint` に置かれる
- [ ] コマンドバーコードを再実行しても板・工程位置・販売位置が重複しない

## 作成工程

- [ ] バナナを取ると工程展示が皮なしの `PeeledBanana` へ変わる
- [ ] キャラクターの左右の手には材料や商品が追加されない
- [ ] バナナより先に棒を取れない
- [ ] 棒を取ると工程表示は皮なし・串なしのまま、串刺し操作が有効になる
- [ ] 「バナナを刺す」と皮なしバナナの前で棒が移動する
- [ ] 棒が差し切られた後、一時モデルが消えて工程展示が `SkeweredBanana` へ変わる
- [ ] 独自アニメーションIDが空でも工程展示の手続き型モーションが見える
- [ ] チョコ筒を選ぶと工程展示の `SkeweredBanana` がいったん消える
- [ ] チョコ筒内の開始点 `ChocolateBananaDipPoint` と一時バナナの開始位置・回転が一致する
- [ ] 一時バナナが終点 `ChocolateBananaDipEndPoint` へ向かって直線移動する
- [ ] 終点をStudioで動かすと、コード変更なしで漬け込みの移動方向も変わる
- [ ] チョコ筒の上に串付きバナナが現れ、バナナ側を下にして筒へ沈んでから上へ戻る
- [ ] 2点がない場合も、CylinderのローカルX軸に沿って筒口から内部へ沈む
- [ ] 漬け込み終了後、一時モデルが消えて工程展示が `DippedBanana` へ変わる
- [ ] 漬け終わると回転できるようになる
- [ ] 登録コマンドで独自 `ParticleEmitter` が `ChocolateBananaEffects/ToppingParticle` へ複製される
- [ ] トッピング開始1秒後に登録した独自ParticleEmitterが工程展示から再生される
- [ ] `ChocolateBananaToppingEffectPoint` がある場合、そのWorldPositionと発生位置が一致する
- [ ] EffectPointを移動・回転すると、コード変更なしでエフェクト位置・向きも変わる
- [ ] 更新後の登録コマンドで再登録すると、元モデルを基準にした位置と向きが再生時にも使われる
- [ ] `ToppingOrientationOffset` を変えるとエフェクトだけを追加回転できる
- [ ] トッピング中に工程展示が小刻みに動く
- [ ] 各工程の完了時に工程展示から光が出て、メッセージが表示される
- [ ] 完成時は通常工程より強い光とUIの弾みが表示される
- [ ] 所持金・スタッフ・確認・通知・ボタンの背景が少し透けて見える
- [ ] チョコ後と完成品に用意したメッシュが使われる
- [ ] 販売ブロックで `DisplayPoint` の位置・回転に商品が置かれる
- [ ] 販売中の商品が残っている間は次の商品を置けない

## 購入と所持金

- [ ] 初回所持金が100円で表示される
- [ ] スタッフは商品を購入できない
- [ ] 一般客が購入すると50円になり、`FinishedBanana` メッシュのToolを受け取る
- [ ] 残高不足では購入できず、商品も残る
- [ ] 同じ商品を2人が同時購入しても1回分だけ処理される

## セキュリティ確認

- [ ] 工程を飛ばして設備を選んでも進まない
- [ ] 別の屋台の設備で工程を進められない
- [ ] RemoteEventへ不正な文字列を送っても状態が変わらない
