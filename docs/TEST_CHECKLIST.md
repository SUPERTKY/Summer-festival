# 動作確認チェックリスト

Studio の **Test → Start** でサーバー1台・プレイヤー2〜3人を起動します。

## スタッフ

- [ ] 募集ブロックへ触れると確認画面が出る
- [ ] 「やめておく」でスタッフにならない
- [ ] 「スタッフになる」で `WorkAnchor` へ移動する
- [ ] 歩行とジャンプはできず、左右回転だけできる
- [ ] 同じ屋台で2人目のスタッフを登録できない
- [ ] 辞任すると移動・ジャンプが元に戻る
- [ ] 退室またはリスポーン後にスタッフ枠が解放される

## 作成工程

- [ ] バナナを取ると左手に表示される
- [ ] バナナより先に棒を取れない
- [ ] 棒を取ると右手に表示される
- [ ] 「バナナを刺す」でアニメーション後に串付きへ変わる
- [ ] チョコ筒を選ぶと筒の方向へ固定される
- [ ] 漬け終わると回転できるようになる
- [ ] トッピング開始1秒後から粒が下向きに3秒流れる
- [ ] 販売ブロックで `DisplayPoint` の位置・回転に商品が置かれる
- [ ] 販売中の商品が残っている間は次の商品を置けない

## 購入と所持金

- [ ] 初回所持金が100円で表示される
- [ ] スタッフは商品を購入できない
- [ ] 一般客が購入すると50円になり、Toolを受け取る
- [ ] 残高不足では購入できず、商品も残る
- [ ] 同じ商品を2人が同時購入しても1回分だけ処理される

## セキュリティ確認

- [ ] 工程を飛ばして設備を選んでも進まない
- [ ] 別の屋台の設備で工程を進められない
- [ ] RemoteEventへ不正な文字列を送っても状態が変わらない
